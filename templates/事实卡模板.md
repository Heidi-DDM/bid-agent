# 项目主卡模板（一项目一卡）

> 字段以 PRD §6.1 为准；非空字段必须绑定来源链接 + 原文摘录；缺失标"待补"，不硬造。
> `company_advantage` 占位 = 待企业资料导入，禁止编造。

```yaml
---
card_id: T-CARD-0001            # 主键，系统生成
project_id: T-PROJ-0001         # 多公告聚合键
project_name: ""                # 公告原文
tender_no: ""                   # 待补
tenderee: ""                    # 招标人
agency: ""                      # 待补
region: ""                      # 省/市/区县
project_type: ""                # 工程/货物/服务
budget_amount: ""               # 待补
ceiling_price: ""               # 待补
bid_bond_amount: ""             # 待补
deadline_signup: ""             # 待补
deadline_bid: ""                # 必填
open_date: ""                   # 待补
qualification_requirements: []  # 子卡引用 ref[]
scoring_rules: []               # 子卡引用 ref[]
company_advantage: [{status: "待企业资料导入"}]
source_links: []                # 必填，每条可点击
confidence: ""                  # confirmed/high/medium/low
status: active                  # active/closed/awarded
---
```
