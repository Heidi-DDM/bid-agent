# 数据源合规记录模板（FR1）

> 每个数据源一条记录。新增数据源必须过法务《数据来源合规清单》后方可启用（R1-R6 红线前置检查）。
> 字段以 PRD §八 为准，缺项标"待确认"不硬造。
> 平台全量清单（级别/URL/接入方式/非公告源剔除）见 schema §1.4 平台注册表（2026-08-18 v0.2.3 冻结，24 行）。

## 数据源基本信息

| 字段 | 值 |
|------|-----|
| 数据源名称 | 例：中国招标投标公共服务平台 |
| 数据源级别 | L0（第三方授权 API）/ L1（官方平台）/ L2（自建采集）/ L3（禁止） |
| 平台 URL | 例：https://ggzyfw.beijing.gov.cn |
| 接入方式 | 官方 API / 授权推送 / 页面采集 |
| 接入状态 | 待接入 / 已接入 / 已暂停 / 已废弃 |

## 合规记录

| 检查项 | 状态 | 说明 |
|--------|:--:|------|
| robots.txt 检查 | ☐ | 禁止路径不采集；记录 robots 文件状态 |
| 采集频率约束 | ☐ | 单源 ≤1 次/5 分钟（正式期定时式） |
| UA 透明 | ☐ | 标识性 UA（含公司信息），不伪装 |
| 授权/合同 | ☐ | L0 需合同授权；L1/L2 需公开接口依据 |
| 法务签字 | ☐ | 《数据来源合规清单》签字日期：____ |
| 个人信息处理 | ☐ | 联系人信息 30 天脱敏策略确认 |
| 失败熔断配置 | ☐ | 单源连续 3 次失败 → 暂停并告警 |

## 合规红线自检（R1-R6）

| # | 红线 | 自检 |
|:--:|------|:--:|
| R1 | 不绕过平台技术保护措施 | ☐ 无验证码破解/登录态模拟/反爬突破 |
| R2 | 不采集非公开信息 | ☐ 仅采集公开公告 |
| R3 | 不干扰平台正常运行 | ☐ 频率低于阈值 |
| R4 | 个人信息最小化 | ☐ 脱敏策略生效 |
| R5 | 数据仅限内部投标用途 | ☐ 无转售/外供 |
| R6 | AI 输出可溯源 | ☐ 每条推送带原文链接 |

## 接入验收（P0）

- [ ] 测试期触发式采集可跑通（手动/单条 URL）
- [ ] 10 条真实公告全流程通过（G0→G4）
- [ ] 法务签字完成
