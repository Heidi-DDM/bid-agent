## R025：RAG 三层知识库、向量索引与证据检索

- **优先级**：P0 ｜ **状态**：in_progress ｜ **迭代**：Iteration 3/4
- **需求描述**：建立以 RAG 为主要信息资料入口的三层知识库：L1 公开可投标信息、L2 完整招标文件条款、L3 企业能力与证据；采用 PostgreSQL + pgvector 的混合检索（关键词/BM25 + 向量 + metadata filter + 可选 reranker），每条结果回链 Material、版本、哈希和页码/段落。RAG 只返回候选证据，严格数字/日期/等级/有效期比对由结构化字段和 F008/F023 确定性规则引擎完成。
- **模型边界**：DeepSeek API 仅处理获准出域的公开数据；企业资料 OCR 与 embedding 在本地/内网执行；任何模型不得生成企业资料、直接输出满足/不满足或投标决定。
- **验收要点**：①三层数据和权限隔离可验证；②混合检索按 project/lot/version/as_of/permission 过滤；③权限泄漏率 0、引用完整率 100%；④L2 条款 Recall@5 ≥ 0.90、L3 证据 Recall@10 ≥ 0.90；⑤数字/日期/等级 exact match ≥ 0.95，失败进入人工复核；⑥索引/检索幂等、版本失效和重放成立；⑦RAG 不得绕过规则引擎或审批门禁。
- **完成情况（2026-09-02）**：R025 运行时阶段 A-F 代码完成（配置与 DeepSeek public-only 出域门禁、0004 迁移 knowledge_data 三表 + pgvector、三层索引流水线、检索 API/RBAC/检索回放、匹配接入与证据快照、审批门禁 stale/缺快照拒绝）；沙盒 `-m "not integration"` 121 passed、`-m rag` 35 passed；真库 integration 5 passed、/readyz 全绿、e2e cosine 0.9239。农大验收首报 `reports/rag_acceptance_nd2025_0902_v1.json`：20 条规则全量 executed=20/complete=true 且与离线金标准 0 差异、引用完整率 1.00、权限泄漏 0；L2 Recall@5=0.85 / L3 Recall@10=1.0（规则派生查询集 < 方案 ≥50 条人工标注线，标为参考值）。**遗留（不阻塞代码完成，阻塞正式验收/不标 done）**：①黄金查询集 ≥50 条双人标注（tests/fixtures/rag 未建）；②exact match ≥200 字段样本待 F022 解析产物；③整档商务标/技术标 PDF 的 L3 索引与投标类 8 类证据结构化入库依赖 R021/R022（planned）；④worker 条款断言直查 L3 召回弱（观察值），F021/F022 后查询改写改善。
