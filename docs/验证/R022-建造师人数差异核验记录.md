# R022 数据核验记录：注册建造师 1145 vs 1181 人数差异说明

> 建立日期：2026-09-02 ｜ 依据：F006 §15 / F007 §14 实测盘点 + r007 演练产物
> 关联：08-开发执行与验收清单 §2.2 第 3 项「对 1145/1181 人数差异形成数据核验记录」

## 1. 差异结论（一句话）

**1181 = 原始行数（xlsx 数据行，含同名重复）；1145 = 按姓名去重后的人数**。
两份数字均来自同一源文件 `3.注册建造师清单（含在施状态).xlsx`，不是口径冲突，是**计数口径不同**。

## 2. 数据来源与计数口径

| 来源 | 记录 | 口径 | 说明 |
|---|---|---|---|
| docs/05-项目现状 §3（2026-08-26 盘点） | **1145 人** | 按姓名去重 | 首次盘点时对主表做姓名去重统计 |
| F007 §14（2026-08-27 r007 演练实测） | **1181 行 / 去重 1145 人** | 行数 vs 去重人数 | 主表 1181 行数据行；同名重复 36 行（1181-1145） |
| 库内 managers 表导入策略 | — | 按 `reg_cert_no + display_name` 幂等键 | R022 导入器幂等键含姓名，同名重复自动 skip，天然去重 |

## 3. 差异构成（2026-08-27 r007 实测明细）

- 主表 xlsx 数据行 **1181 行**；
- 按「姓名」列去重后 **1145 人**（同名 36 人——同一人持多专业列勾选/多行在施记录，或确有同名）；
- 附加 Sheet（1002 行在施信息）**不计数**（在施状态挂主表人员，非独立人员）；
- 注册编号/联系电话 1181 条全为「后续补充」占位符 → 导入映射为 `__待补__`（F006 §6.4）。

## 4. 对导入与匹配的影响

1. **不产生重复主键**：R022 导入器按业务键（建造师：category+姓名+专业+注册编号）幂等，
   同名重复行第二次导入 skipped（实测：1181 行源 → managers 导入去重后仅 1 条同名不同专业可共存）。
2. **注册编号缺失 = 缺证**：匹配引擎 `project_manager` 规则若要求注册证（NQ-H-003 要求
   注册建造师+B证），`reg_cert_no=__待补__` 的记录在核验前不参与准入（pending_verification），
   核验人补充证据（证书扫描件 OCR）后转 active 才可被匹配读到——**缺失即阻断是产品特性，非缺陷**。
3. **后续校准责任**：36 条同名重复是否真为同一人（多专业注册）需人力资源确认，
   正式期（D2+）由数据管理员在核验流程逐条确认，本记录不擅自合并或删除任何行。

## 5. 核验结论

| 项 | 结论 |
|---|---|
| 两份数字是否矛盾 | 否，口径不同（行数 1181 vs 去重人数 1145） |
| 数据源是否唯一 | 是，同一 xlsx 主表 |
| 是否影响导入正确性 | 否，导入器幂等去重 + 缺证待核验，无重复主键风险 |
| 待办（不阻塞 D1） | 同名 36 行人工归并确认（人力资源）；注册编号/电话补录（核验人） |
