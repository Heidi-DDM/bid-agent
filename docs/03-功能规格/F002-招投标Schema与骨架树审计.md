# F002-招投标Schema与骨架树审计

- **需求来源**：R002 ｜ **状态**：定稿（Iteration 1 已执行审计与激活）
- **关联**：ADR-001、`投标智能体-智库底座复用方案_v1.md` §四、`schema/`、F003、F008

## 1. 背景与目标

- **背景**：既有招投标骨架树（复用方案 §四细化版 v1）与 `schema/schema.md`（v0.3.x）覆盖"信息收集"域；新增"资格/资源核查层"（ADR-001）需要骨架树与 Schema 扩展匹配/项目经理/满分准入节点，并重新审计。
- **目标**：审计既有骨架树与 Schema；新增节点；通过审计门禁后激活，成为字段唯一事实源。

## 2. 非目标

- 不重写既有采集域节点（G0-G6′、L0-L3、去重、事实卡保留）；不引入智库行业分析维度。

## 3. 用户角色与端到端步骤

| 角色 | 步骤 |
|---|---|
| 知识工程师 | ①盘点既有骨架树与 schema；②对照 ADR-001 确定新增节点；③起草新增叶子节点；④提交审计 |
| 投标专员/经营负责人 | 评审新增节点（匹配维度、项目经理字段、准入状态） |
| 开发 | 依据审计通过的 schema 冻结字段 |

端到端步骤：盘点 → 差异分析 → 起草 → 审计（coverage/占位/冲突）→ 修复 → 激活。

## 4. 数据对象

- `schema/tender_skeleton_tree.json`（机器可读骨架树）、`schema/schema.md`（域操作规范）、`schema/schema_draft.md`（生成稿）、`schema/_schema_generation_log.md`（审计轨迹）。
- 唯一 ID：节点路径（如 2.3.1）；Schema 版本号（semver）。
- 状态：draft / audited / active / deprecated。

## 5. 输入/输出与证据要求

- 输入：旧骨架树、ADR-001、真实公告/招标文件样例。
- 输出：审计后的骨架树 + schema + 审计日志。
- 证据要求：每个新增节点注明出处（旧 PRD 条款/ADR/真实文件样例），不允许无来源字段。

## 6. 业务规则

1. 骨架树新增域（建议）：九、资格与资源核查域（企业资料匹配、项目经理、满分准入）、十、准入状态机域；与既有 G0-G6′ 门禁衔接（匹配与审批作为 G3.5/G7 或独立门禁，Iteration 1 定稿）——**已定稿（2026-08-25，R002）**：骨架树第 9/10 章落地；匹配门禁命名 **G3.5**（schema §6.4），独立于公开情报推送（G4）；审批为状态机终点（§12.2），不增设 G7 门禁。
2. 字段冲突处理：与旧 PRD 冲突的字段须显式登记差异并引用 ADR——**已执行（2026-08-25）**：旧优势卡占位 `match_result`（满足/部分满足/待核实/不满足）vs 匹配矩阵 `match_result`（satisfied/partial/not_satisfied/unverifiable）差异登记于 schema §11.1 与审计日志 §8.2，旧占位不静默覆盖。
3. 审计门禁：coverage 100%、placeholder 0、无重复定义——**已通过（2026-08-25）**：coverage 107/107、placeholder 0、tree id 唯一性校验通过。
4. 激活后字段 key 不可随意修改；变更走文档变更流程。

## 7. 失败/空态/异常状态

- 审计失败：列出未覆盖/占位/冲突项，修复后重审。
- 占位节点：标注"待确认"并登记到 `docs/05-项目现状.md` §5。

## 8. API 目标态契约

- 无对外 API；schema 为数据契约源，供 F008 规则引擎与后端实现引用。

## 9. 权限、数据隔离、审计和合规

- schema 属公开层规则，无敏感数据；审计日志保留。

## 10. 验收标准与测试计划

- 验收：①新增节点齐全；②审计 coverage 100%；③与 ADR-001 状态机一致；④与旧 PRD §六字段无冲突（或有登记差异）。
  - **验收结果（2026-08-25，R002）**：①新增节点齐全（骨架树第 9/10 章，schema §十一/§十二）；②审计 coverage 107/107、placeholder 0；③准入状态机 12 态与 ADR-001 §2.2 逐状态一致；④差异已登记（旧优势卡占位 vs 匹配矩阵 `match_result`，schema §11.1）。
- 测试计划：真实公告/招标文件样例试填，验证字段可提取率——**待 Iteration 1 R004/R005 执行**（需真实/脱敏招标文件样例，见 `docs/05-项目现状.md` §5 待确认项 7）。
