# F009-投标审批与人工豁免审计

- **需求来源**：R010 ｜ **状态**：draft v1.1（Iteration 2/3 冻结）
- **关联**：ADR-001 §2.2/§2.5（状态机、人工豁免）、F008（准入结果）、F010（审批页原型）

## 1. 背景与目标

- **背景**：新增业务要求第 4 条——最终"是否投标"由企业经营/投标负责人审批；系统输出证据化匹配结论与准入状态，不得自动代表公司作出法律或商业承诺。
- **目标**：定义审批/驳回/人工豁免工作流与审计要求；满分 ≠ 自动投标，只进入 `pending_bid_approval` 等待人工决策。

## 2. 非目标

- 不自动投标、不自动签章、不自动报价；不替代审批人的商业判断。

## 3. 用户角色与端到端步骤

| 角色 | 步骤 |
|---|---|
| 经营负责人（审批人） | 查看人工补录后的准入结果/证据 → 审批通过 / 驳回 / 发起豁免 |
| 投标专员 | 发起豁免申请（带理由与证据）→ 补充待补材料 |
| 数据管理员 | 核验豁免涉及的证据 |

端到端步骤：自动匹配 → 风险/缺失处置与人工补录重算 → `qualified_full_score` → `pending_bid_approval` → 审批人查看最新结果 → 审批/驳回/豁免 → `approved_for_bidding` / `rejected_by_approver` → 归档（保留审计）。

## 4. 数据对象

### 4.1 审批记录（ApprovalRecord）

| 字段 | key | 说明 |
|---|---|---|
| 审批ID | `approval_id` | 主键 |
| 项目ID | `project_id` | |
| 审批人 | `approver` | 经营负责人 |
| 决策 | `decision` | approved / rejected / waived |
| 决策时间 | `decided_at` | |
| 意见 | `comment` | 必填（驳回时） |
| 关联准入结果 | `admission_result_ref` | 回链 F008 |

### 4.2 人工豁免（Waiver）

| 字段 | key | 说明 |
|---|---|---|
| 豁免ID | `waiver_id` | 主键 |
| 授权人 | `authorizer` | 审批人 |
| 原因 | `reason` | 必填 |
| 证据 | `evidence_refs` | 必填（在途材料/受理回执等） |
| 有效期 | `valid_until` | 必填，过期自动失效 |
| 审批时间 | `approved_at` | |
| 覆盖的阻断项 | `covered_items[]` | 具体豁免哪项 |

## 5. 输入/输出与证据要求

- 输入：F008 准入结果（满分判定 + 阻断/待补清单）。
- 输出：审批/驳回/豁免记录 + 审计流。
- 证据要求：审批人决策基于证据化匹配结论；豁免必须附证据与有效期。

## 6. 业务规则

1. **满分 ≠ 自动投标**：满分只进入 pending_bid_approval；无审批人 approved 不得进入投标准备。
2. 审批人变更须有权限配置（名单由经营负责人确认，Iteration 3 冻结）。
3. 豁免不改变"满分"定义，只允许带着豁免项进入人工审批视野；豁免到期未批准 → 回到阻断状态。
4. 驳回必须填写意见；全部动作留审计（谁、何时、依据、结论）。
5. 审批/驳回/豁免记录随项目归档保留（审计期限待法务确认）。

## 7. 失败/空态/异常状态

| 状态 | 处置 |
|---|---|
| 未到满分 | 不进审批队列（F008 阻断） |
| 审批人未配置 | 队列停留，提示配置审批人 |
| 豁免过期 | 自动失效 + 回到阻断 |
| 权限不足 | 非审批人只读/不可见 |

## 8. API 目标态契约

```text
GET  /api/v1/approvals/pending                    # 待投标审批队列
POST /api/v1/projects/{id}/approval/approve       # 审批通过
POST /api/v1/projects/{id}/approval/reject        # 驳回（comment 必填）
POST /api/v1/projects/{id}/waivers                # 创建豁免
GET  /api/v1/projects/{id}/audit                  # 审计记录（含豁免）
```

## 9. 权限、数据隔离、审计和合规

- 审批层数据仅审批人/授权角色可见（F003 权限矩阵 approver_only）。
- 审计记录不可删改；豁免证据留存。

## 10. 验收标准与测试计划

- 验收：①审批/驳回/豁免流程可走通；②豁免字段齐备且过期失效；③审计完整；④无自动投标路径。
- 测试计划：审批流用例、驳回必填校验、豁免过期用例、权限用例、审计完整性用例。
