## 4. 当前原则与约束

1. **只用手动触发**：测试期 `manual_trigger`（人工粘贴公告/上传招标文件/单条 URL），**不启动定时采集**（`scheduled` 须待 P0 验收 + 法务签字）。
2. **运行时状态如实记录**：R018→R019→R020→R025 已完成代码与真库验证（R025 农大质量指标验收进行中，见 §3 与 04-修改日志）；R021-R024（入库解析/企业资料 OCR/匹配审批服务化）为 planned，农大为唯一运行时试点，下一步按 R021→R022→R023→R024 开发。
3. **敏感资产不入库**：企业资料、招标文件、原始抓取内容、密钥、Cookie、数据库、日志、构建产物一律不提交 Git（见 `docs/00-项目规则.md` §6 与 `.gitignore`）。
4. **RAG 只作证据入口**：RAG 检索结果必须标为候选证据；金额/日期/等级/有效期由结构化字段和确定性规则引擎核验，向量分数不得参与准入公式。
4. **缺失不编造**：任何缺失字段显示"待补/待核实"，禁止编造。
