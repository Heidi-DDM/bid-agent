1. **只用手动触发**：测试期 `manual_trigger`（人工粘贴公告/上传招标文件/单条 URL），**不启动定时采集**（`scheduled` 须待 P0 验收 + 法务签字）。
2. **不开发业务代码**：当前处于 Iteration 0 文档治理期；原型（Iteration 2）、薄切片（Iteration 4）均未排期执行。
3. **敏感资产不入库**：企业资料、招标文件、原始抓取内容、密钥、Cookie、数据库、日志、构建产物一律不提交 Git（见 `docs/00-项目规则.md` §6 与 `.gitignore`）。
4. **缺失不编造**：任何缺失字段显示"待补/待核实"，禁止编造。
