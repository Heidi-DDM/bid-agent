## 3. 证据化验收清单

### D1 演示退出条件

- [ ] 农大单项目从手动入库到审批全流程成功，且重复投递/重算幂等。
- [ ] 20/20 条规则均有执行记录；与人工金标准逐条对照并记录差异。
- [ ] 每条结论均有 clause 引用和企业 evidence 引用；引用完整率 100%。
- [ ] NQ-H-007 等缺证项保持 `unverifiable/blocked_missing_data`，不得推断满足。
- [ ] 权限负例跨项目访问为 403，公开层与企业层无泄漏。
- [ ] 解析失败、OCR 低置信度、模型不可用均进入可解释复核/重试状态。
- [ ] 演示环境、样本和限制清单交付，明确“不支持批量采集、不自动投标、不代表生产安全”。

### D2 受限生产退出条件

- [ ] 正式认证、角色权限、密钥管理、HTTPS 和对象存储 ACL 完成部署验证。

- [ ] R025 黄金查询集至少 50 条、双人标注；L2/L3 Recall 达到规格阈值 0.90。

- [ ] 客户完成用户验收并确认评分规则、资料责任人、审批人和限制边界。

### D3 规模化退出条件
