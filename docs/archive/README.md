## 使用约定

1. 归档文件保留原名，可加 `_archived_YYYYMMDD` 后缀避免与活跃文档混淆。
2. 归档必须在 `docs/04-修改日志.md` 与源文档"变更记录"中双向登记。
3. 严禁归档本应删除的敏感数据（企业资料、招标文件、密钥等）——敏感数据应物理删除或移出仓库，不得入库。
