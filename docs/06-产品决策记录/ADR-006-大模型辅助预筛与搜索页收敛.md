# ADR-006：大模型辅助预筛与搜索页收敛

- **状态**：已接受
- **日期**：2026-09-22
- **关联**：ADR-005、F026、docs/10 §5 P4（LLM 受约束兜底方法论）

## 背景

ADR-005 决策 1 将预筛限定为纯确定性规则（标题/类型词命中），规则未命中一律"待人工查看"。2026-09-22 用户实测反馈：待选池中大量条目落入「需人工确认」（生效规则行业词过窄、招租/租赁等类型词缺口），智能筛选感缺失；用户明确要求"脚本抓取之后用大模型智能筛选"，同时要求搜索页去掉与待选池重复的候选展示。

## 决策

1. **确定性规则仍是第一层**（公告类型/行业词/排除词），本 ADR 不改变其语义与红线。
2. **新增第二层：大模型辅助预筛**，对第一层未判定（`needs_manual_review`）的候选，按标题做**受约束的事实性分类**：
   - 只输出：公告类别（封闭词表：工程/市政/房建/EPC/水利/勘察设计/设备/服务/政府采购/信息化/非招标-招租租赁/非招标-中标结果/非招标-政策法规/非招标-新闻动态/非招标-其他）、是否属于可投招标机会（yes/no/uncertain）、依据词、置信度；
   - **依据词必须是标题子串**（机器校验），校验不过该条回落人工，不入库结论；
   - LLM 判定"非招标公告"（招租/结果/政策/新闻等）且置信度 ≥ 中 → 自动移出待处理（`pool_status=expired`，`screening.excluded_by="llm"` 留审计），**可一键恢复**（人工 `restore` 回 `needs_manual_review`）；
   - LLM 判定相关/行业类别只用于**排序与徽标展示**，不改变人工处理义务；
   - **永不输出**"值得投/不建议投/中标率"等商业判断——分类是事实判断，不是投标建议；
   - 开关关闭 / 出域门禁不过 / 网络失败 → 零副作用回落人工（fail-open 到 `needs_manual_review`，不阻断搜索主链）。
3. **搜索页收敛**：搜索页只保留触发（表单/健康检查/任务状态/逐源摘要）与**增量简报收口**，不再展示任何候选列表（含只读诊断视图）；候选的查看与处理**唯一入口是待选池**。最近搜索任务仅作任务状态记录（状态/数量/删除），不再提供打开候选。
4. 招租/租赁/资产处置/产权交易补入确定性非招标类型词表（第一层直接排除，不依赖 LLM）。

## 后果与边界

- 待选池成为唯一筛选工作台；「需人工确认」剩余条目 = 确定性规则与 LLM 均未能确证分类的条目（量应显著下降）。
- LLM 排除可恢复、留审计（模型、依据词、时间）；误排责任可追溯，与"数据缺失默认阻断、不推断满足"的既有红线不冲突——排除仅影响展示分流，不删除任何候选事实。
- 公开情报层仍只保存原文事实；LLM 分类结论作为**规则执行记录**存储于待选池 screening，不写回公告原文事实。
- 复用 docs/10 P4 的不变量方法论：契约校验、封闭词表、依据可验证、失败零副作用。
