# 投标智能体 · 可点击原型（R011 / F010）

> 对应需求：R011（可点击原型与目标用户验证）｜ 规格：`docs/03-功能规格/F010-投标准入原型与用户验证.md`
> 状态：Iteration 2 交付，供 Iteration 3 用户验证使用

## 一、这是什么

纯静态可点击原型（HTML/CSS/JS，无构建、无后端、无依赖），用**脱敏真实案例**演示“联网搜索招标数据 → 人工选择深入 → 上传完整招标文件 → 解析 → 自动匹配已解析企业资料 → 风险/缺失 → 人工补录 → 人工审核”的最小闭环。原型只用于用户验证流程，**不实现真实计算引擎、不接数据库、不做权限系统实现**（F010 §2）。

## 二、如何运行

任意静态服务器即可，例如：

```bash
cd prototype && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

直接双击 `index.html` 也可浏览（页面间跳转使用相对路径）。

## 三、用户旅程（6 步）

| 步骤 | 页面 | 说明 |
|---|---|---|
| 1 | `index.html` | 联网搜索招标数据，生成结构化公告事实卡 |
| 2 | `import.html` | 人工选择深入项目，上传完整招标文件并解析（原文不可变、多版本、sha256） |
| 3 | `matrix.html` | 解析结果 + 自动匹配矩阵；自动读取已解析且已核验的企业资料 |
| 4 | `score.html` | 展示风险项、缺失项、阻断状态和逐条证据，不重复触发匹配 |
| 5 | `queue.html` | 人工补录缺失材料、登记复核、触发重新匹配 |
| 6 | `approval.html` | 经营负责人人工审核、驳回/豁免/审计；**非审批角色访问显示 403** |
| — | `exceptions.html` | 5 类异常态演示：空态 / 资料过期 / 解析失败 / 权限不足 / 无合格项目经理 |

右上角**角色切换器**（投标专员/数据管理员/经营负责人/法务）模拟登录，切换后审批页权限随之变化。

## 四、数据口径

- 主旅程数据 = `验证受限材料/农大/`（河北农业大学东校区研究生宿舍建设项目施工，事后验证样本，已中标）
  - 20 条规则与 `scripts/matching/golden_requirements_nongda.json` 一致（hard 12 / scored 4 / action 4）
  - 匹配矩阵与 `nongda_match_result.json` 一致：hard 11/12 satisfied、NQ-H-007 待补（财务审计素材缺口）、主观 2 项人工复核、客观类似业绩双 satisfied（2.5+2.5）
  - 审批记录与 `approval_demo_result.json` 一致；**待审批条目为补齐材料后的构造口径，仅用于演示审批流**
- 异常态案例：康保储能 EPC（空态）、广宗葫芦中学（资料过期）、阜平高铁片区管网（解析部分完成）、无合格经理（构造）
- 所有名称按 F007 §6.4 脱敏；本项目目录 Git 白名单内（`prototype/` 可提交）

## 五、业务红线在原型中的体现

1. 满分 ≠ 自动投标：风险结果页与人工审核页均有明确文案，最终决定由经营负责人完成（ADR-001 §2.3）
2. 数据缺失默认阻断：NQ-H-007 显示“待补/不可判定”，不推断满足
3. 硬性缺项一票否决：广宗案例展示 expired → blocked_hard_requirement
4. 无合格项目经理：候选 0 人 → 风险与缺失页提示，准入阻断，不生成不存在的经理
5. 纯事实红线：导入/解析页只展示原文事实与解析状态，无分析断语
6. 审计留痕：审批/驳回/豁免全部动作记录谁/何时/依据/结论

## 六、文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 搜索招标数据与结构化推送 |
| `import.html` | 选择深入项目、上传完整文件与解析 |
| `matrix.html` | 解析结果 + 自动匹配矩阵 + 证据抽屉 |
| `materials.html` | 企业资料库后台：五类资料全量台账（资质/业绩/项目经理/人员/证据文件，滚动+分页）与 Excel/CSV 受控导入 |
| `profile.html` | 企业画像：按投标评分维度四分类总览资料解析/核验/证据覆盖情况（F027，只读聚合，不构成资格结论或投标建议） |
| `score.html` | 风险与缺失结果 |
| `queue.html` | 风险处置、人工补录与重算 |
| `approval.html` | 人工审核/驳回/豁免/审计 |
| `exceptions.html` | 5 类异常态演示 |
| `styles.css` | 共享样式（行业招投标/公共资源交易风格） |
| `data.js` | 脱敏演示数据（唯一数据源） |
| `common.js` | 公共组件（导航/步骤条/抽屉/角色） |
